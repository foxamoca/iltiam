## Conventions

- English and Arabic versions use the same file name; the Arabic one adds `.ar`.
- Requirement IDs (F-, BR-, FR-, NFR-, UF-) are defined in the PRD and reused
  across all documents. Do not renumber them.
- Source tags: **[C]** confirmed, **[A]** assumption, **[D]** delegated,
  **[T]** tentative.
